A configuration you can learn from

Community templates include package choices and access profiles. Every revision stays available, and a fork records the exact revision it came from. Your machine name, network addresses, SSH public key, disk choices, and build password stay out of shared templates.

Save privately first. When you choose to share for other members to use and adapt, all template revisions, titles, and revision notes become public. Making a template private removes it from the library, but cannot recall copies already made.

Help shape Blunix

Share useful configurations, report installation problems, and help test accessibility. Be respectful, keep personal information out of public titles and notes, and use the report button on a configuration that needs maintainer review.
